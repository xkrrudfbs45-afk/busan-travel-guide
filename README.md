# Busan, Made Easier

An English-language static travel guide for visitors to Busan, South Korea.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server. Paths use root-relative URLs and are intended for a domain-root deployment.

## Content and editorial checks

- Verify transport schedules, fares, pass conditions and official links before publication.
- Keep affiliate relationships disclosed clearly.
- Update the privacy policy before enabling analytics, advertising or other data collection.
- Add a sitemap and canonical domain after the production URL is stable.

## Deployment

The site can be deployed as a static site on Render with the repository root as the publish directory and no build command.
