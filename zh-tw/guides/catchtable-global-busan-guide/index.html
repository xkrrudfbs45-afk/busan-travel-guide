釜山餐廳預約指南：Catchtable Global 海外旅客使用教學

透過海外旅客版本 Catchtable Global，查詢合作店家、預約座位或加入候位名單。

BUSAN TRAVEL4 MIN READCHECK BEFORE BOOKING

Quick answer: Use Catchtable Global for participating restaurants. Check whether the restaurant offers a reservation, remote waitlist or on-site waiting; these are different services.

1. 使用 Global 國際版

Catchtable Global 是為海外旅客設計的版本。韓國觀光公社指出，可透過 Google、Apple 或電子郵件註冊，不需要韓國手機號碼，並支援包含繁體中文、日文與英文在內的 20 種語言。

2. 先確認店家提供哪種功能

進入餐廳頁面後，查看是否有「Reserve」（預約）、「Join Remote Waitlist」（遠端候位），或僅提供現場候位說明。預約功能可選擇可訂時段；遠端候位可在抵達前加入隊伍。若只有現場候位，就必須到店登記。

3. 哪些情況需要訂金？

部分只接受預約的餐廳會收取訂金，Catchtable Global 可使用海外發行的信用卡付款。VISITKOREA 說明，遠端或現場候位本身不需要訂金。訂金金額、取消期限與未到店規則依店家而異，確認前務必閱讀條款。

4. 到店前確認清單

確認分店、日期、時間與人數；也要分清楚自己拿到的是正式訂位，還是候位號碼。開啟 App 與電子郵件通知，留意候位進度，接近叫號時準時前往。

5. 不是每家店都在平台上

只有加入平台並開啟相關功能的店家才能使用 Catchtable。部分釜山在地老店可能只接受現場排隊，或使用其他系統。若頁面沒有預約或候位按鈕，不要自行認定可以線上訂位。
