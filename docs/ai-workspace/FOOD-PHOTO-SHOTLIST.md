# Go2Busan Food Photography Shot List

_Last updated: 2026-11-10_

목표는 장식용 음식 사진을 많이 모으는 것이 아니라, 실제 방문 경험과 메뉴 선택에 도움이 되는 원본 사진을 확보하는 것이다. 방문하지 않은 식당의 사진을 방문 후기처럼 사용하지 않는다. AI 이미지는 실제 음식·매장 사진을 대체하지 않는다.

## 1. 촬영 기본 원칙

- **직접 촬영 우선:** Go2Busan 팀 또는 기고자가 실제 방문해 촬영한 사진을 우선 사용한다.
- **사실성:** 메뉴·양·가격·매장 상태를 오해하게 만드는 과도한 보정, 합성, 색상 변경은 하지 않는다.
- **출처와 권리:** 직접 촬영은 Photo: Go2Busan으로 표기한다. 외부 사진은 사용 허가 또는 라이선스를 확인하고 원 출처와 라이선스를 함께 기록한다.
- **인물·개인정보:** 직원과 손님 얼굴, 차량 번호, 결제 정보가 식별되면 게시 전 동의를 받거나 가린다.
- **매장 촬영:** 내부·메뉴판 촬영이 제한되는지 먼저 확인한다. 촬영을 거절하면 따르며, 식사 중 다른 손님을 방해하지 않는다.
- **가격 정보:** 메뉴판 사진을 찍더라도 가격은 게시 직전 다시 확인한다. 사진 촬영 날짜를 기록하고 오래된 가격은 현재 가격처럼 소개하지 않는다.
- **모바일 우선:** 음식의 핵심이 작은 화면에서도 보이도록 세로 4:5와 가로 16:9 구도를 모두 확보한다. 가능하면 원본 고해상도 파일을 보관한다.

## 2. 모든 식당 공통 필수 컷

각 식당에서 가능한 범위 내 아래 컷을 확보한다.

1. **대표 음식 전체 컷:** 음식과 그릇이 한눈에 보이도록 45도 각도.
2. **질감·재료 클로즈업:** 국물, 고기, 면, 채소 등 실제 차별점이 보이게.
3. **한 상 차림:** 메인 메뉴와 반찬, 소스, 수저 등 실제 제공 구성을 보여준다.
4. **메뉴판·가격:** 게시 시점의 메뉴와 가격을 확인할 수 있는 컷. 가격이 바뀌면 사진은 참고용으로만 사용.
5. **매장 외관·간판:** 정확한 상호와 지점 확인이 가능하도록 촬영.
6. **골목·주변 맥락:** 입구를 찾기 쉽게 주변 거리나 시장 동선을 담는다.

## 4. 촬영 후 파일 관리

권장 파일명:

YYYYMMDD_area_restaurant_subject_sequence.jpg

예시:

- 20261115_nampo_18beon_wandang_01.jpg
- 20261115_seomyeon_songjeong_gukbap_01.jpg
- 20261116_pnu_seomun_noodles_01.jpg

각 사진과 함께 아래 메모를 남긴다.

- 촬영 날짜와 시간
- 식당의 정확한 한글 상호·지점
- 주문한 메뉴와 실제 결제 금액
- 직접 방문 여부 및 촬영자
- 공개 가능한지, 매장 촬영 허가가 필요한지
- 얼굴·차량번호 등 식별 정보가 포함됐는지

## 5. 게시 전 검수

- [ ] 사진 속 식당과 본문에 적힌 식당이 동일하다.
- [ ] 지점과 주소가 맞다.
- [ ] 직접 방문하지 않았다면 방문 후기처럼 표현하지 않았다.
- [ ] 사진의 촬영일과 가격·메뉴의 기준일을 구분했다.
- [ ] 외부 이미지라면 라이선스·출처·표기를 확인했다.
- [ ] 모바일 화면에서 음식이 잘리지 않고 핵심이 보인다.
- [ ] 이미지 대체 텍스트는 사진에 실제로 보이는 내용만 설명한다.
- [ ] 사진 속 손님·직원 개인정보를 확인했다.

**운영 원칙:** 좋은 사진이 없으면 이미지를 억지로 채우지 않는다. 정확한 정보와 실제 촬영 자료가 준비될 때까지 텍스트와 지도 정보로 충분히 안내한다.
