# Instagram 이미지·카드 개선 제안 — 2026-11-19

## 원칙
이 문서는 승인된 게시물의 이미지 교체를 실행하지 않는 별도 제안이다. 기존 `instagram-state` 이미지, 활성 schedule, 게시 상태는 변경하지 않았다. 새 아트는 AI 삽화로 명확히 표기하고, 실제 장소 사진을 쓸 경우 출처·라이선스·귀속을 먼저 확인한다.

## 시스템 개선 제안
현재 `scripts/instagram/art.mjs`의 `STYLE_PLACE`와 `STYLE_PLACE_BRIGHT`는 모든 삽화에 “Busan is a sea-facing port city; show the sea, coastline or harbour wherever it fits”를 공통 적용한다. 이 규칙이 서면·실내·음식 장면의 장소 부정확성을 유발한다.

새 `art.scene` 옵션을 도입해 장면별 스타일을 분리한다.
- `coastal-urban`: Haeundae처럼 해안이 주제인 장면
- `inland`: Seomyeon·서면 상권
- `market-food`: 시장·음식·식당
- `indoor`: 우천 대안·실내 관광
- `coastal-nature`: Taejongdae처럼 자연 해안·절벽
- `travel-still-life`: 준비물·체크리스트

기존 승인 게시물은 이 옵션을 적용하거나 재렌더하지 않는다. 새 장면 스타일은 향후 신규 초안 또는 사용자 승인 후 새 아트 세트 ID를 부여한 경우에만 사용한다. 실제 사진을 선택하면 별도 라이선스·귀속 검증을 통과해야 한다.
