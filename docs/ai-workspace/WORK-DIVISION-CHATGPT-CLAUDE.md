# Go2Busan 업무 분담 및 병렬 작업 운영 규칙
작성일: 2026-11-12
적용 저장소: xkrrudfbs45-afk/busan-travel-guide
기준 시장: 대만(繁體中文, zh-TW) 우선 / 일본어·영어 병행

## 1. 운영 원칙
ChatGPT와 Claude는 같은 파일을 동시에 수정하지 않는다. 모든 작업은 독립 브랜치와 PR로 제출하고, PR 본문에 담당 영역·수정 파일·검증 결과·미완료 항목을 기록한다. main 병합, 실제 사이트 배포, SNS 예약 변경·발행, GA4 설정 변경, 비밀키 및 외부 계정 변경은 소유자 승인 없이 하지 않는다.

## 2. ChatGPT 담당: 콘텐츠·편집·여행자 경험
주요 책임:
- 부산 맛집·골목·시장·관광 콘텐츠 기획과 본문 작성
- 한국어 원자료와 현지 공개 자료를 대조해 사실관계·주소·메뉴·동선·주의사항 정리
- 대만 번체 중심의 자연스러운 현지화 문안과 일본어·영어 콘텐츠 편집
- 콘텐츠 구조, 독자 질문, 방문 전 체크리스트, 지역별 여행 동선과 내부 링크 제안
- 이미지 기획, 실제 촬영 사진 반영 계획, 사진 출처·라이선스 표기 검수
- SNS 게시물의 문안·주제 다양성·중복·국가별 문화 적합성 검수(초안 단계)

콘텐츠 담당의 수정 범위:
- 본문 카피, 설명문, 맛집 소개, 여행 팁, 편집상 H1/본문 제목, 콘텐츠 섹션과 본문 내 관련 링크
- 단, title/meta description, Open Graph/Twitter metadata, JSON-LD, canonical, hreflang, sitemap, robots, 검색 인덱스, analytics, schema, 성능·접근성 코드는 기술 담당에게 맡긴다.
- 같은 HTML 파일에서 콘텐츠와 기술 SEO 수정이 모두 필요하면 한 PR에서 혼합하지 않는다. 먼저 콘텐츠 PR을 올리고, Claude가 별도 PR에서 메타데이터 등 기술 영역을 처리한다.

현재 ChatGPT 콘텐츠 작업:
- PR #361: 대만 번체 맛집 가이드 25곳 → 28곳 확장. 깡통골목할매 유부전골, 남포쭈꾸미, 당감동 할매쭈꾸미 추가. 기존 25개 항목 보존. 새 3곳은 《釜山日報》가 직접 소개한 곳으로 오인되지 않도록 Go2Busan 자체 추가 선정으로 구분.
- #361에서는 기술 SEO metadata와 JSON-LD를 main 기준으로 복원해 콘텐츠 변경만 남긴다. 기술 SEO 변경은 별도 담당 PR로 분리한다.
- 콘텐츠 문안에 직접 방문한 것처럼 쓰지 않는다. 확인하지 못한 영업시간·가격·휴무는 단정하지 말고 확인 필요로 표시한다.

## 3. Claude 담당: 개발·기술 SEO·데이터·품질보증
주요 책임:
- 기능 개발, UI/UX 구현, 반응형·모바일 최적화, 접근성, 성능
- 기술 SEO: title/meta description, OG/Twitter, JSON-LD, canonical, hreflang, sitemap, robots, 내부 검색 인덱스
- 빌드·테스트·CI, HTML 유효성, 링크 검사, 이미지 최적화, 구조화 데이터 검증
- GA4/GTM 이벤트 계측, UTM 규칙, Search Console/GA4 데이터 파이프라인 및 리포트
- Instagram·Threads 자동발행 코드, 시간대 변환, 중복 방지, 실패 재시도, 예약 스케줄 검증
- 배포 자동화·모니터링·오류 로그 점검(실제 운영 변경은 승인 필요)

현재 Claude 우선 작업:
1. PR #360: 대만 BTS 가이드 검색 스니펫 개선. 기술 SEO 담당으로 title/meta/OG/Twitter/JSON-LD를 검토하고, Taiwan 검색 의도와 페이지 본문 일치 여부를 확인한다. CI 및 기술 SEO 검증 결과를 PR에 남긴다.
2. PR #361은 콘텐츠 전용이다. 해당 페이지의 기술 SEO metadata/JSON-LD를 별도 PR로 개선할 필요가 있으면 #361의 파일 변경과 충돌하지 않도록 별도 브랜치에서 작업하고, 콘텐츠 PR 병합 후 rebase/재검증한다.
3. 기존 열린 PR을 전수 분류한다. 중복 파일·상호 충돌·기준 브랜치 오래된 PR·CI 누락을 표로 정리하고, 독립적으로 검증 가능한 묶음으로 정리한다.
4. GA4/Search Console: 대만 유입 기준선과 UTM 누락, (not set), 소셜 유입 미집계, affiliate_click과 purchase 구분을 점검한다. 계정 설정이나 태그 변경은 별도 승인 요청한다.
5. SNS 자동발행: 기존 15일치 및 135개 초안은 draft와 승인된 schedule을 구분한다. 이미지 렌더링·링크·현지 시간대·중복 검수는 하되 승인 없이 live schedule을 수정하거나 발행하지 않는다.

## 4. PR 파일 소유권과 충돌 방지
- ChatGPT: 콘텐츠 본문과 편집 카피. 새 콘텐츠 PR은 콘텐츠 파일만 변경.
- Claude: 기술 SEO head metadata, JSON-LD, sitemap, robots, 검색 인덱스, CSS/JS, 빌드·테스트·워크플로·analytics.
- 동일 파일의 동시 편집 금지. 수정이 겹치면 먼저 PR 담당자에게 코멘트로 조정하고, 콘텐츠 PR과 기술 PR을 순차 병합한다.
- 콘텐츠 변경 PR에서 SEO title/meta/OG/JSON-LD를 임의로 함께 바꾸지 않는다.
- 코드와 데이터가 필요하면 별도 PR로 분리한다.

## 5. 공통 완료 기준
각 PR에는 다음을 기록한다.
- 수정 목적과 사용자 영향
- 변경 파일 목록 및 변경 범위
- 근거 자료와 확인 날짜
- 사실 확인이 끝나지 않은 항목
- CI/테스트/링크/모바일 검수 결과
- 병합·배포 여부를 명확히 구분
- 후속 작업과 담당자
