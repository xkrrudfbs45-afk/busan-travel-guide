## 1. 측정 기반 (P0)

1. ~~내부 트래픽 제외~~ — 소유자가 이미 설정함(제외). 필터는 설정 이후 데이터부터 적용되므로 과거 28일 수치에는 운영자 조회가 섞여 있을 수 있다.
2. **Search Console–GA4 연결.** 소유자가 진행할 대기 항목이다. 연결 후 랜딩 페이지별 자연검색 → 제휴 클릭 흐름을 한 보고서로 본다.
3. **CTA 이벤트에 위치 정보 추가.** affiliate_cta_view와 affiliate_click에 `cta_id`와 `cta_position`(top/mid/bottom)을 보낸다. 기존 이벤트명과 매개변수는 유지하고 추가만 한다. 어떤 위치의 CTA가 눌리는지 알 수 없는 상태를 해소한다.
4. **주간 통계 자동 문서.** 매주 월요일 SC 7일 비교, GA4 이벤트, 상위·하위 페이지를 docs/ai-workspace/STATS-YYYY-MM-DD.md 하나로 정리한다. 현재는 수동 확인 문서가 흩어져 있다.

## 2. 검색 CTR 개선 — 이미 노출되는 페이지 (P1, 효과 가장 빠름)

5. **EN 빛축제 페이지.** 순위 3.6위인데 CTR 0.7%다. 제목에 "Dates, Hours & Map"처럼 검색 의도와 정확한 기간(Nov 28–Jan 10)을 넣고, 설명 첫 문장에 18:00–23:00과 무료 입장을 넣는다.
6. **zh-cn 김해공항 페이지.** 순위 2.5위, 노출 119회, 클릭 0이다. 간체 제목과 설명이 검색어(金海机场到釜山市区 등)와 맞는지 점검한다. 노출 국가가 중국 본토인지 SC 국가 필터로 확인한다.
7. **스파랜드 / 해운대 맛집 / 시티투어버스 / VBP(zh-tw).** 순위 10~17위, CTR 0~1.4%다. 제목·설명을 재작성하고, 본문 상단에 30초 요약 박스(가격·시간·위치)를 넣는다.
8. **things-to-do-in-busan.** 순위 70위로 사실상 검색 경쟁력이 없다. 허브 페이지 역할로 두고 SEO 목표에서는 제외한다. 대신 상위 시의성 페이지로 보내는 내부 링크 허브로 재구성한다.
9. **BTS 페이지.** #690 효과를 12/11경 비교한다. 개선이 없으면 FAQ(위치·운영시간·교통)를 추가해 스니펫을 노린다.
10. **"釜山鯊魚還在嗎" 같은 질문형 검색어 대응.** zh-TW 북항 상어 페이지 맨 위에 현재 상태 답변을 날짜와 함께 한 줄로 둔다. CTR 25%대를 유지하면서 순위를 올린다.

## 4. 제휴 전환 (P2, 매출 직결)

15. **CTA 위치 재배치.** cta_view 도달률이 8%이므로 첫 화면 아래(요약 박스 직후)에 맥락형 CTA 1개를 둔다. 예: 드론쇼 → 광안리 오션뷰 숙소, 빛축제 → 해운대 숙소. 페이지당 최대 2개를 유지한다.

17. **시즌 상품 매칭표.** 12~1월(빛축제·크리스마스·해돋이)과 3~4월(벚꽃)에 맞는 Klook 상품과 Agoda 지역을 페이지별로 매핑한다. content/affiliate/*.json으로 관리한다.

## 6. 기술 SEO (P6)
