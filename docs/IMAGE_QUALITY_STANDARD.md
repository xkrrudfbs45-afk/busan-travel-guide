# Go2Busan 이미지 품질·운영 기준

> 목적: 사진과 시각 요소만으로도 부산 여행의 매력을 전달하고, 검색 유입·페이지 경험·제휴 전환을 함께 개선한다.
> 적용 범위: 대만 번체(zh-TW) 최우선, 영어(en)·일본어(ja) 및 한국어 원천 페이지 전체.

## 1. 상시 점검 원칙

모든 정기 콘텐츠·SEO·UX 점검에서 이미지 품질을 독립 항목으로 확인한다. 신규 글을 늘리는 것보다 기존 유입 페이지와 핵심 랜딩 페이지의 이미지 품질을 먼저 개선한다.

우선순위는 다음과 같다.
1. 국가별 핵심 랜딩 페이지의 첫 화면 대표 이미지와 썸네일
2. 음식 가이드의 음식·메뉴 사진과 실제 소개 항목의 일치 여부
3. 관광지·동네·교통 가이드의 장소 식별력과 사진의 현장 적합성
4. 모바일 화면에서의 크롭, 피사체 잘림, 가독성, 로딩 속도
5. OG·SNS 공유 이미지와 국가별 콘텐츠 크리에이티브
6. 오래되거나 중복되거나 깨진 이미지, 낮은 해상도·과도한 용량

## 2. 사진 선정과 신뢰성

- 실제 장소·음식·서비스와 사진이 정확히 일치해야 한다. 다른 지점이나 유사 메뉴 사진을 실제 사진처럼 사용하지 않는다.
- 직접 방문·촬영 여부를 확인할 수 없는 경우 방문했다고 표현하지 않는다.
- 공식 제공 이미지, 사용 허가를 받은 이미지, 라이선스가 명확한 이미지, 적법하게 확보한 자체 촬영 이미지를 우선한다.
- 이미지별 출처, 라이선스/사용 허가 근거, 확인일을 기록한다. 사용 권한이 불명확하면 게시하거나 교체하지 말고 확인 과제로 남긴다.
- 오래된 행사·계절·가격·시설 상태를 보여주는 사진은 현재 정보와 맞는지 재검증한다.
- AI 생성 이미지는 실제 부산의 특정 장소·음식 사진으로 오인시키지 않는다. 삽화·컨셉 이미지로 명확히 구분하고, 실제 현장 사진이 필요한 맥락에서는 대체재로 쓰지 않는다.

## 3. 국가별 시각 현지화

- 대만 번체: 대만 여행자가 이해하기 쉬운 맥락과 정보 우선순위를 적용하되, 부산의 실제 장소·문화적 맥락을 왜곡하지 않는다.
- 영어: 처음 방문하는 해외 여행자가 장소와 이동 상황을 직관적으로 이해할 수 있도록 대표 장면과 정보성 이미지를 배치한다.
- 일본어: 일정·동선·지역 특성을 파악하기 쉬운 사진 순서와 썸네일을 사용한다.
- 동일 이미지를 언어별로 기계적으로 반복하기보다 해당 페이지의 검색 의도와 독자 맥락에 맞는 이미지를 선택한다. 다만 국가별 차이를 만들기 위한 근거 없는 사진 교체는 하지 않는다.

## 4. 기술·접근성 체크리스트

- [ ] 이미지 URL 응답 정상 여부(404/5xx 포함)
- [ ] 적절한 크기·해상도와 반응형 이미지(srcset/sizes 등) 적용
- [ ] WebP/AVIF 등 효율적 포맷 사용 여부와 원본 품질 확인
- [ ] 파일 용량 최적화 및 불필요한 중복 이미지 제거
- [ ] 첫 화면 핵심 이미지의 우선 로딩과 비핵심 이미지 lazy loading 구분
- [ ] 이미지 영역의 크기 예약 등으로 CLS 최소화
- [ ] LCP 후보 이미지의 크기·전송·우선순위 점검
- [ ] 의미 있는 대체 텍스트(alt) 작성: 장식 이미지는 빈 alt 적용, 키워드 나열 금지
- [ ] 파일명과 캡션은 이미지 내용을 정확하게 설명
- [ ] OG/Twitter 공유 이미지의 비율·크롭·언어별 적합성 확인
- [ ] 구조화 데이터·이미지 사이트맵이 실제 이미지 URL 및 페이지 정보와 일치하는지 점검(적용 대상에 한함)
- [ ] 모바일·데스크톱 주요 뷰포트에서 크롭과 표시 상태 확인

## 5. 데이터 기반 개선 우선순위

이미지 개선 후보를 선정할 때 다음 데이터를 함께 본다.
- Search Console: 국가·언어·페이지별 노출, 클릭, CTR, 평균 순위 및 검색 의도
- GA4: 국가·언어·랜딩 페이지별 세션, 참여, 주요 이벤트 및 affiliate_click
- 기술 지표: LCP·CLS·이미지 로딩 실패·페이지 무게
- SNS: 국가별 썸네일/크리에이티브 반응과 사이트 유입

표본이 작거나 측정 동의·어트리뷰션 제약이 있으면 한계를 명시한다. affiliate_click을 예약·구매·매출로 간주하지 않는다. 개선 전후 비교는 동일한 기간·조건을 기준으로 하고, 확인되지 않은 효과를 단정하지 않는다.

## 6. 변경·검수·배포 절차

1. 페이지 URL, 언어, 현재 이미지, 문제 유형, 근거, 제안 이미지를 기록한다.
2. 이미지 출처·라이선스·장소/메뉴 일치 여부를 확인한다.
3. 모바일·데스크톱, alt, 파일 크기, 로딩, OG 표시를 검수한다.
4. 관련 변경을 독립 브랜치와 Draft PR로 제출하고 테스트 결과 및 이미지 출처를 PR 본문에 남긴다.
5. PR 병합과 운영 배포는 소유자의 별도 승인을 받은 뒤 진행한다.

자동화 점검은 공개 페이지의 이미지 상태를 읽기 전용으로 확인할 수 있다. 외부 SNS 게시물·예약물 변경, 이미지 라이브러리 대량 교체, 유료 이미지 구매, 라이선스가 불명확한 이미지 사용은 사전 승인 없이 실행하지 않는다.

## 7. 회차별 보고 형식

각 점검 보고서에 아래 항목을 포함한다.
- 국가/언어별 이미지 취약 페이지와 우선순위
- 대표 이미지·음식/장소 적합성 문제
- 모바일 크롭·접근성·성능·OG 문제
- 이미지 출처·라이선스 확인 상태
- 수정 파일·브랜치·PR·CI 상태
- 승인 또는 추가 확인이 필요한 사항

변경할 근거가 없으면 불필요하게 이미지를 교체하지 않고 '변경 없음'과 점검 근거를 기록한다.
