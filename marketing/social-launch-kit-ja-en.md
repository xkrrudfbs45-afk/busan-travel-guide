# Go2Busan Japan & USA — Social Launch Kit

Status: editorial draft for review. This file is an internal publishing aid; it does not publish posts or change the live website.

## Brand rules

- Keep the same Go2Busan wordmark, bridge symbol, navy/ocean-blue/coral/cream palette, and overall thumbnail system across both accounts.
- Localize the language and examples; do not make the accounts look like unrelated brands.
- Lead with a useful travel question or specific benefit. Avoid generic “Visit Busan!” copy.
- Use only verified locations, transport details, opening hours, prices, and images with appropriate usage rights.
- Each post should have one clear CTA. Link to the most relevant guide, not automatically to the homepage.
- Profile names to consider: `Go2Busan Japan | 釜山旅行` and `Go2Busan USA | Busan Travel`. Check platform availability before use.

## UTM conventions

Use these campaign links in the profile link hub or post links where the platform supports clickable links. If Instagram captions do not support clickable links, say “Link in bio” and use the matching URL in the profile link hub.

- Japan: `utm_source=instagram&utm_medium=social&utm_campaign=launch_2026_11&utm_content=ja_<post-slug>`
- USA: `utm_source=instagram&utm_medium=social&utm_campaign=launch_2026_11&utm_content=en_<post-slug>`

Example:
`https://go2busan.com/ja/guides/three-days/?utm_source=instagram&utm_medium=social&utm_campaign=launch_2026_11&utm_content=ja_three_day_plan`

## Publishing cadence for the first two weeks

- Publish 3 posts per week per account; adapt the same core visual system rather than translating word-for-word.
- Use 3–5 relevant hashtags, mixing destination and intent terms. Example Japan: `#釜山旅行 #韓国旅行 #釜山グルメ`. Example USA: `#Busan #SouthKoreaTravel #BusanFood`.
- Add descriptive alt text where the platform supports it.
- Reply to genuine questions with useful answers; do not use engagement bait.
- Record results after 48 hours and again after 7 days: reach, saves, shares, profile visits, link clicks, and sessions landing on the target guide.
- Do not claim “local favorite,” “hidden gem,” “best,” or “secret” unless the content substantiates the claim.

## Measurement checklist

For each post, record:
- Account / language
- Post slug and publication date
- Reach and non-follower reach
- Saves and shares
- Profile visits and link clicks
- Website sessions with the matching UTM campaign/content
- Guide engagement (next-page clicks or engaged sessions, if available)

**Decision rule after 14 days:** repeat the topics that produce saves/shares and measurable guide visits. If reach is high but site visits are low, improve the CTA and profile link path before increasing posting volume.
