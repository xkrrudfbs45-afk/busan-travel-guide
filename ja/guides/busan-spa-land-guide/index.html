1. スパランドはどこ？

スパランドは釜山・海雲台区の新世界センタムシティ百貨店1階にあります。釜山地下鉄2号線でセンタムシティ駅へ。駅から商業施設に接続しているため、建物内では「Spa Land」の案内表示をたどると見つけやすいです。地上から向かう場合、観光案内では12番出口方面が案内されています。

住所：釜山広域市海雲台区センタム南大路35（新世界センタムシティ）。タクシーでは「신세계백화점 센텀시티점 스파랜드」と表示すると伝わりやすくなります。詳しくはVisit Busanの案内も確認できます。

2. 営業時間と入場料

公式案内に掲載されている情報は次のとおりです。祝日などは変更の可能性があるため、当日も確認してください。

  • 営業時間：09:00〜22:00
  • 最終入場：21:00
  • 大人：26,000ウォン
  • 学生：21,000ウォン
  • 基本利用時間：最大4時間
  • 超過料金：1時間ごとに5,000ウォン
  • 延長条件：入場料を除き館内で10,000ウォン以上利用すると、最大6時間まで利用できる場合があります。
  • 駐車：基本4時間無料。条件を満たす館内利用で最大6時間無料と案内されています。

小学生以上の入場条件や学生料金の対象は、年齢・在学確認などの条件が関係する場合があります。子ども連れの場合は事前に施設へ確認してください。

3. 入場から利用まで

  1. 入口を探す：百貨店内の「Spa Land」表示に従います。
  2. 受付：当日のチケット購入・受付方法に従い、ロッカーキーや利用券をなくさないようにします。
  3. 大きな荷物を預ける：スーツケースは浴場内のロッカーエリアに持ち込めません。必要に応じて受付付近の荷物預かりを利用します。
  4. 浴場を利用：浴場は男女別です。入浴前にシャワーを浴び、掲示されているルールを守ります。
  5. 共用サウナへ：共用のチムジルバン・休憩エリアでは施設指定の館内着を着用します。
  6. 時間を確認：着替えや退出時間も考慮し、利用時間内に出られるようにします。

韓国のチムジルバンでは、男女別の浴場と共用サウナエリアで利用方法が異なります。浴場では通常水着を着用せず、共用エリアでは館内着を着ます。不安があればスタッフに確認してください。浴場や更衣室での撮影は避け、施設のプライバシールールに従いましょう。

4. スーツケースと荷物預かり

ホテルのチェックイン前に立ち寄る場合は、荷物のサイズに注意してください。公式案内の荷物預かり料金は以下のとおりです。

  • 最初の5時間：3,000ウォン
  • 追加1時間ごと：1,000ウォン

入場料とは別料金です。大型・特殊サイズの荷物や複数のスーツケースがある場合は、預け入れ可能か先に確認すると安心です。

5. どれくらい滞在する？

浴場、複数のサウナルーム、食事、休憩を楽しむなら、初回は2〜4時間ほどを目安にすると計画しやすいでしょう。通常の利用時間は最大4時間で、超過料金や延長条件が設定されています。営業時間は22時までなので、宿泊施設の代わりに夜通し滞在する計画は立てないでください。

スパランドの前後に詰め込みすぎない

入浴・着替え・休憩に加えて、館内移動や退出時間も必要です。訪問後に別エリアへ移動する場合は、センタムシティからの交通時間も含めて予定を組みましょう。

6. 周辺と組み合わせるなら

地下鉄駅に直結した大型商業施設内にあるため、雨の日、寒い日、暑い日の屋内プランに向いています。百貨店での買い物や食事と組み合わせるのも便利です。釜山はエリア間の移動に時間がかかるため、次の目的地までの経路を確認してから予定を組みましょう。

よくある質問

スパランドはどこにありますか？

新世界センタムシティ百貨店の1階にあります。釜山地下鉄2号線センタムシティ駅から商業施設に接続しています。

入場料はいくらですか？

公式案内では大人26,000ウォン、学生21,000ウォンです。通常の利用時間は最大4時間です。最新条件は公式ページで確認してください。

スーツケースを持ち込めますか？

大きなスーツケースは館内ロッカーエリアに持ち込めません。荷物預かりは最初の5時間3,000ウォン、以降1時間ごとに1,000ウォンと案内されています。

初めてチムジルバンを利用するときの注意点は？

浴場は男女別で、通常は水着を着用せず利用します。共用のサウナ・休憩エリアでは施設指定の館内着を着用してください。

出発前に：公式ページで営業時間・料金・荷物ルールを確認してください。
