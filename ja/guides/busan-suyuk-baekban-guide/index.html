釜山のスユクペッパン（ゆで豚定食）ガイド

ゆで豚を主役にした定食を楽しむための実用ガイド。料理の特徴、注文方法、店ごとに異なる食卓の内容を紹介します。

Quick answer: Suyuk baekban is a boiled-pork set meal, not another name for dwaeji-gukbap. Soup and side dishes vary by restaurant.

1. スユクペッパンとは？

スユクペッパンは、ゆでた豚肉を薄切りにした「スユク」を主役に、ご飯などと一緒に味わう韓国の定食です。豚肉とスープが中心のテジクッパとは異なります。肉の部位や厚さ、盛り付けは店によって違います。

2. 定食には何が付く？

ご飯、スープ、副菜（パンチャン）が付くことがありますが、組み合わせは決まっていません。スープが別に出る店もあれば、セット内容が異なる店もあります。メニューで確認しましょう。

3. おすすめの食べ方

まずは豚肉そのものの味を試してみましょう。ニラの和え物、アミの塩辛、つけだれがあれば、好みに合わせて少しずつ加えてください。これらは必須ではなく、店によって提供内容が異なります。

4. 注文に使える韓国語

수육백반 주세요.（スユクペッパンをください。）スープが付くか聞きたいときは、국도 같이 나와요?（スープも一緒に出ますか？）と尋ねられます。

5. どこで食べられる？

韓国観光公社のVISITKOREAでは、西面のソンジョンサムデクッパがスユクペッパンを提供する店として紹介されています。Visit Busanは蓮堤区のスボクテジクッパでもおすすめメニューとして掲載しています。訪問前に最新のメニュー、価格、営業時間を確認してください。
